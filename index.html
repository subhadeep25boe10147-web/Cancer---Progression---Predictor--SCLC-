Method context

Designed for
exploration, not care.

This web experience adapts the source project’s cancer progression workflow into a browser interface. It visualizes cyclic stretch while providing a transparent, illustrative score based on the submitted variables. A production research deployment should connect this interface to a versioned, validated model service and follow appropriate data-governance practices.

About the score

An exploratory signal, not a clinical result.

The value is returned by the project’s trained Random Forest model, scaled from 0 to 1. Risk labels describe model ranges only and must never be used to diagnose, predict outcomes, or guide treatment.
